# REST API для блога на Go

Дипломная работа завершает программу «Go-разработчик с нуля».

В проекте вы создадите простое REST API для блог-платформы, включающее регистрацию пользователей, авторизацию, создание постов, комментарии, логирование и корректную обработку ошибок.

Задание позволяет применить основные навыки, полученные в программе: работу с Go, JSON, HTTP-сервером, файлами, простейшими конкурентными механизмами, Docker и базовой структурой проекта.

## 1. Цель дипломной работы

По итогам выполнения проекта студент должен продемонстрировать:
· владение основами синтаксиса Go (функции, структуры, модули);\
· умение работать с файлами и JSON;\
· понимание принципов построения HTTP-сервера и REST API;\
· базовые навыки аутентификации и авторизации;\
· понимание обработки ошибок и логирования;\
· минимальное использование конкурентности Go (работа с горутиной и каналом) для одной простой задачи;\
· умение структурировать проект по директориям;\
· способность собрать и запустить приложение через Docker.\

Все требования соответствуют уровню начинающего разработчика.

## 2. Чек-лист готовности

Перед началом убедитесь, что:
· установлен Go версии 1.21+;\
· установлен Docker и Docker Compose;\
· вы знакомы с основами HTTP в Go;\
· умеете работать с JSON и файлами;\
· используете Git;\
· ознакомились с темами модулей по Go и многопоточности.

## 4. Задание

Разработайте REST API для блог-платформы.\
Хранение данных — в JSON-файлах.База данных допускается, но не обязательна.

### 4.1. Функциональные требования

1. Управление пользователями
    Эндпоинты\
        · POST /register\
        · POST /login\
    Требования\
        · уникальный email/username;\
        · хэширование пароля (bcrypt);\
        · при входе — выдача простого токена (JWT или самодельного);\
        · корректные статусы и сообщения об ошибках.

2. Управление постами
    Эндпоинты
        · POST /posts\
        · GET /posts\
        · GET /posts/{id}\
    Требования\
        · авторизация обязательна для создания;\
        · поля: id, author_id, title, content, created_at;\
        · валидация title и content;\
        · корректные HTTP-коды.

3. Комментарии
    Эндпоинты:\
        · POST /posts/{id}/comments\
        · GET /posts/{id}/comments\
    Требования:\
        · комментировать могут только авторизованные;\
        · у комментария есть id, post_id, author_id, text, created_at.

4. Состояние сервиса
· GET /health → {“status”: “ok”}


### 4.2. Обязательный дополнительный функционал

Отложенное логирование действий пользователя
Каждый раз, когда пользователь:\
· создаёт пост,\
· создаёт комментарий,

— вы отправляете строку-событие в канал:
"user 5 created post 12"

В отдельной горутине работает воркер, который:
· получает сообщения из канала,\
· записывает их в файл log.txt с задержкой 1–2 секунды,\
· корректно завершает работу при остановке сервера.

5. Технические требования
· Go 1.21+\
· Хранение данных: JSON-файлы (или БД по желанию)\
· Чёткая структура директорий (handlers, storage, models, auth, logger)\
· Все ответы в формате JSON\
· Валидация входных данных\
· Логирование (в консоль + в файл через горутину)\
· Обработка ошибок\
· Dockerfile + docker-compose.yml\
· Код отформатирован go fmt

## 6. Этапы выполнения проекта
Этап 1. Настройка окружения
Установка Go, Docker; создание .env; подготовка проекта.

Этап 2. Используйте шаблон по ссылке
